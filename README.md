# 🌲 SYNAPSE & ÁRBOLES ANCESTRALES
### Conexión Arbórea & Bio-Gimbal Somático ante Momentos Turbulentos

Plataforma interactiva de regeneración somática que combina la bio-energía de árboles ancestrales con la sensibilidad de un bio-gimbal para purificar las ramificaciones del sistema nervioso central y estabilizar el organismo durante crisis y estrés personal.

---

## 🌟 Características Principales

1. **El Bio-Gimbal Somático (Amortiguador ante Momentos Turbulentos)**:
   - **Simulador Interactivo de Onda Somática**: Monitor en vivo que compara el estado de turbulencia (cortisol, vibración errática) frente al estado de amortiguación arbórea (coherencia cardíaca, ritmo vagal suave).
   - **Calibrador de Sensibilidad 3-Ejes**: Ajuste de amortiguación (0.2x a 2.0x) con presets: *Equilibrio Suave*, *Firmeza Dinámica*, *Paz Profunda Zen* y *Enraizamiento Fijo (Horizon Lock)*.
   - **Audio Armónico de Bosque**: Síntesis de ondas sonoras de 432 Hz generadas con la Web Audio API (sin archivos de audio externos requeridos).

2. **Simulador de Conexión & Alianza con Árboles Ancestrales**:
   - Catálogo interactivo de 8 árboles sagrados:
     - **Roble Ancestral**: Enraizamiento pélvico y resiliencia ante crisis.
     - **Sauce de Río**: Flexibilidad neuromuscular y liberación de dolor reprimido.
     - **Eucalipto de Montaña**: Oxigenación torácica y fitoncidas purificantes.
     - **Pino Silvestre & Cedro**: Depuración sanguínea por bio-terpenos.
     - **Abedul Blanco**: Drenaje linfático y renovación dérmica.
     - **Ceiba Sagrada**: Perspectiva superior y conexión con la corona.
     - **Olivo Centenario**: Desinflamación mitocondrial y sosiego.
     - **Higuera Sagrada**: Calma del ritmo cardíaco y apertura afectiva.
   - **Mándala de Resonancia en Vivo**: Muestra visualmente las raíces y pulsos electromagnéticos.
   - **Métricas Biométricas en Tiempo Real**: Enraizamiento (%), Depuración Linfática (%), Amortiguación de Turbulencia (%) y Claridad de Copa (%).
   - **Certificado de Alianza Arbórea**: Modal imprimible en PDF con sello del santuario.

3. **Arquitecto de Rutas & Expediciones All-Inclusive**:
   - **Santuarios Forestales**: Bosque de Robles, Selva Nubosa o Valle Fluvial.
   - **Movilidad Suave**: Bicicleta Gravel / E-Bike asistida o Auto Eléctrico con suspensión suave.
   - **Rituales de Bosque**: Temazcal ceremonial con hojas medicinales de tus árboles, masaje neuro-sedante con resinas, regeneración dérmica y corte de cabello ritual.
   - **Emprendimientos Locales**: Catas de miel melipona de bosque, cacao criollo de sombra, destilación de resinas y quesos de pastoreo.
   - **Libros Curados**: *La Vida Secreta de los Árboles*, *El Cuerpo Lleva la Cuenta*, *Shinrin-Yoku*, *La Mente Serena*.
   - **Filmmaker Personal (Gimbal 3-Ejes 4K)**: Documentación discreta de la transformación.

4. **El Pequeño Reel (Formato 9:16)**:
   - Reproductor con marco de smartphone e interfaz de cámara Ronin (4K REC 60FPS).
   - Casos reales documentados (superación de duelo, crisis vocacional, reconexión afectiva).
   - Botón *"Cargar Este Paquete en el Simulador"* para clonar cualquier ruta con un solo click.

## 🚀 Despliegue en GitHub & GitHub Pages

Para publicar este proyecto gratis en internet usando **GitHub Pages**:

```bash
# 1. Inicializar repositorio Git
git init

# 2. Agregar los archivos
git add .

# 3. Crear el primer commit
git commit -m "feat: initial release de Synapse & Árboles Ancestrales"

# 4. Vincular con tu repositorio de GitHub (reemplaza con tu URL)
git remote add origin https://github.com/TU-USUARIO/synapse-arboles.git

# 5. Subir a la rama principal
git branch -M main
git push -u origin main
```

### Para activarlo como sitio web (GitHub Pages):
1. Ve a tu repositorio en GitHub: **Settings** -> **Pages**.
2. En **Build and deployment** > **Branch**, selecciona `main` y la carpeta `/(root)`.
3. Haz click en **Save**.
4. En 1-2 minutos, tu página estará disponible en:
   `https://TU-USUARIO.github.io/synapse-arboles/`
